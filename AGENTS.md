# Repository instructions

## Git identity

- Use `jyjyxt <im.jyjyxt@gmail.com>` as both the author and committer for commits created in this repository.
- Before creating a commit, check `git var GIT_AUTHOR_IDENT` and `git var GIT_COMMITTER_IDENT` and confirm that both match the repository identity.
- If the identity needs configuring, use `git config --local user.name jyjyxt` and `git config --local user.email im.jyjyxt@gmail.com`. Do not change the global Git identity.
